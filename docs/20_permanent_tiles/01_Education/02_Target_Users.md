Education Tile — Target Users

Purpose

The Education Tile of Nandika is designed as a complete lifelong learning ecosystem.

It is not limited to school students or traditional education pathways.

The Education Tile supports every user who wants to:

- Learn
- Improve knowledge
- Develop skills
- Change careers
- Gain qualifications
- Explore opportunities
- Share knowledge
- Continue personal growth throughout life

Every user can have multiple roles and can enter the Education ecosystem at different life stages.

---

Core User Philosophy

One User — Multiple Learning Journeys

A single user may be:

- Student + Creator
- Professional + Learner
- Parent + Guide
- Teacher + Content Contributor
- Entrepreneur + Skill Developer
- Senior Citizen + Knowledge Sharer

Nandika does not force users into fixed categories.

Users choose their own learning path according to:

- Interest
- Goal
- Current status
- Skills
- Experience
- Future plans
