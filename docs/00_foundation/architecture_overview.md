**Platform Name:** Nandika

**Version:** 1.0

# 1. Purpose

This document defines the overall architecture of the Nandika platform.

It explains how different parts of Nandika connect together:

- Users
- 26 Tiles
- Universal Growth Engine
- AnnS AI
- Data Systems
- Applications
- Backend Services
- Future Expansion


Architecture principle:

> "One Platform for All Kinds of Users, powered by intelligent, connected and scalable systems."
