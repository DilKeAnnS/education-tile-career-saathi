## Version 2.0

## Status

# 1. Document Purpose

This document defines the high-level architecture of the Nandika Platform.

It describes how different systems, modules, data structures, AI capabilities and future expansion plans work together.

Nandika is designed as:

> One Platform for All Kinds of Users


The architecture is created to support:

- Students
- Parents
- Teachers
- Professionals
- Job seekers
- Job switchers
- Entrepreneurs
- Organisations
- Citizens
- Future global users
