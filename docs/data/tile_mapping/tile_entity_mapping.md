Nandika Tile Entity Mapping

Document Purpose

The Nandika Tile Entity Mapping defines how the 26 Permanent Nandika Tiles connect with the common Nandika Data Foundation.

This document ensures:

- Every tile has equal importance
- No tile becomes limited to one user group
- No ecosystem is isolated
- All tiles use the same platform foundation
- Future ecosystems can be added without changing the core architecture
