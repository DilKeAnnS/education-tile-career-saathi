# Nandika UI/UX Standard

## Version 1.0

---

# 1. Purpose

This document defines how Nandika should look, feel, and interact with users.

UI (User Interface) defines:

- Visual design
- Screens
- Components
- Layout
- Navigation


UX (User Experience) defines:

- How easily users understand the platform
- How comfortably they complete tasks
- How confidently they use features


The goal:

> Create a digital experience where every person can access knowledge, opportunities, and support easily.

---

# 2. Nandika UI/UX Philosophy

Nandika is designed for everyone.

The interface should not assume:

- High technical knowledge
- Young age
- English fluency
- Expensive devices
- Fast internet


The design should follow:

Simple for beginners


Powerful for experts


Accessible for everyone

---

# 3. User-Centric Design Principle

Every design decision should start with the user.

Before creating any screen, ask:

1. Who will use this?
2. What problem are they solving?
3. What information do they need?
4. What is the simplest way to help them?


Example:

A student searching for a career path and a researcher searching for collaboration are different users.

The platform should adapt according to their needs.

# 37. AnnS AI User Experience Standard

## Purpose

AnnS AI is the intelligent assistance layer of Nandika.

It should not behave like a simple chatbot.

It should understand:

- User intention
- User background
- User knowledge level
- User preferred language
- User preferred explanation style

The goal:

> Provide the right answer, in the right language, at the right level, for the right person.

---

# 38. Adaptive Language & Explanation System

AnnS AI should analyse user input and respond accordingly.

Factors:

- Language used by user
- Complexity of question
- User profile (if available)
- Previous interaction preferences
- Required depth of explanation

Example:

Question:

"What is AI?"

For a student:

"AI means teaching computers to learn and perform tasks that normally require human intelligence."

For an engineering student:

"AI uses algorithms, data, and computational models to enable machines to recognise patterns and make decisions."

For a researcher:

"AI involves computational approaches such as machine learning, deep learning, and reasoning systems for solving complex problems."

Same question.

Different explanation.

# 39. Language Support Principle

# 40. Simple Language Mode

For beginners and general users:

AnnS AI should:

- Avoid unnecessary technical words.
- Explain difficult terms.
- Use examples.
- Use step-by-step guidance.

Example:

Instead of:

"Photosynthesis is a biochemical conversion process."

Explain:

"Plants make their food using sunlight, water, and carbon dioxide. This process is called photosynthesis."
